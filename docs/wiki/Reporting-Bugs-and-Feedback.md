# Reporting Bugs and Feedback

*Italiano: [[Segnalare bug e dare feedback|Reporting-Bugs-and-Feedback-it]]*

- **A bug**: open an issue with the [Bug report](https://github.com/Finland6738/azeroth-threatwarden/issues/new/choose)
  form. From `v0.1.0`, type `/atw debug` in the game, press Ctrl+C in the box that opens and paste the report: it has
  no player names.
- **An idea or a question**: start a topic in the
  [Feedback discussions](https://github.com/Finland6738/azeroth-threatwarden/discussions/categories/feedback).
- **A check in the game** (for testers): use the *In-game test report* form.

Please never paste other players' names, whispers or folder paths from your PC; write `<player>` instead.
