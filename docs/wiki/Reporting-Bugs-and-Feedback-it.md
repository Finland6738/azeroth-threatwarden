# Segnalare bug e dare feedback

*English: [[Reporting Bugs and Feedback|Reporting-Bugs-and-Feedback]]*

- **Un bug**: apri una issue con il modulo [Bug report](https://github.com/Finland6738/azeroth-threatwarden/issues/new/choose)
  (in inglese). Dalla `v0.1.0`, scrivi `/atw debug` nel gioco, premi Ctrl+C nella casella che si apre e incolla il
  report: non contiene nomi di giocatori.
- **Un'idea o una domanda**: apri un argomento nelle
  [discussioni di feedback](https://github.com/Finland6738/azeroth-threatwarden/discussions/categories/feedback).
- **Una prova nel gioco** (per i tester): usa il modulo *In-game test report*.

Non incollare mai nomi di altri giocatori, sussurri o percorsi del tuo PC; scrivi `<player>` al loro posto.
