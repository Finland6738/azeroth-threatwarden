# In-game checklists

The offline tests prove that the code agrees with our assumptions about the client; these checklists prove that the
client agrees with the code. Each milestone ends with one, `M<N>.md`, written in its last step and run by the owner in
WoW Forever ([SPEC-08 §4](../specs/SPEC-08-quality-probe-release.md#4-prove-nel-client)); `release.md` is the full check
before `v1.0.0`. Results are reported with the *In-game test report* issue form.
