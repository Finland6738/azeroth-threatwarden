# M6 in-game check: Threat Analytics and export

The offline tests prove that the code agrees with our assumptions about the client; this checklist proves that the
client agrees with the code. It checks the exit criterion of [milestone M6](../roadmap/M6-analytics-export.md) (*every
metric shown can be traced to recorded samples; "Insufficient data" appears where it must; an export can be copied as
text or CSV, with names replaceable*). It is **not done yet**: nobody has run the addon on WoW Forever. Analytics and
export were written before the [M0 probe](../spike/README.md) was run, on assumptions.

**They stand on the recording.** Analytics and export only read recorded sessions and save nothing, so a wrong value
there is a wrong number here. Run the probe and the [M4](M4.md) and [M5](M5.md) checklists first or in the same
sessions; the recordings made there can be used here. The manual pages [Threat Analytics](../wiki/Threat-Analytics.md)
and [Privacy and Data](../wiki/Privacy-and-Data.md) describe what you should see; the rules are in
[SPEC-06](../specs/SPEC-06-analytics-export.md) (Italian).

Report the results with the [*In-game test report* form](https://github.com/Finland6738/azeroth-threatwarden/issues/new?template=ingame_test.yml)
(*Check*: for example `M6 step 3.2`) and note them in the table [at the end](#result). One report for everything that
passed is enough; open one per thing that did not.

**A missing number is not always a bug.** *Insufficient data*, *Not available*, *Not comparable* or *at least …* with a
reason is the right answer when the recording does not hold enough. What must never happen: an invented number, a
missing value shown or exported as 0, a ranking of people or a word of blame, a text that names a cause or an ability,
anything sent or posted in chat, or a Lua error.

## What you need

- WoW Forever; a **party** with a tank and a damage dealer, a **dungeon** (trash and a boss) and a **raid** if you can;
  an enemy with many hit points or a training dummy.
- A spreadsheet (LibreOffice Calc, Excel or similar), a plain text editor, and a Discord channel of your own (a private
  server is enough) to paste into. **Do not paste real names where others read them without their agreement.**
- On the PC, as in the [M2 checklist](M2.md#what-you-need), a development copy of an up-to-date `main` (or the released
  `v0.6.0`).
- Lua errors visible: `/console scriptErrors 1`, or BugSack.
- **Back up your saved data first**, with the game closed. Copy both files somewhere else:
  - `<WoW folder>/_forever_/WTF/Account/<account>/SavedVariables/AzerothThreatwarden.lua` (settings and recordings);
  - `<WoW folder>/_forever_/WTF/Account/<account>/<realm>/<character>/SavedVariables/AzerothThreatwarden.lua` (window
    place and size), for each character you use.

  M6 changes no saved data (account schema 5, character schema 2, as `v0.5.0`). The files hold the names of your
  companions: do not attach them to an issue.

Then install:

```bash
python -I -X utf8 tools/fetch_libs.py
```

```bash
python -I -X utf8 tools/install_addon.py
```

- **Switches.** Until `v0.6.0`, `analytics` and `export` are **off** in a copy of `main`. Turn them on in the
  **installed copy only**: with a text editor open
  `<WoW folder>/_forever_/Interface/AddOns/AzerothThreatwarden/Core/Features.lua`, change `analytics = false,` to
  `analytics = true,` and `export = false,` to `export = true,`, save, then `/reload`. Change nothing else, do not edit
  the repository, and **do it again after every install** (the installer replaces the folder). With the released
  `v0.6.0` there is nothing to edit.
- Check: `/atw debug` *Features* lists `analytics`, `export`, `reports`, `recording`, `timeline` and `replay` after
  `on:`, and the *Analytics and export* section says `switches: analytics on, export on`.
- Settings at their defaults (*Reset settings*): *Record fights* on, *When* **In a group or instance**, rate **2 Hz**,
  thresholds **82 % / 91 %**. Check that the *Recording* card keeps enough recordings for the fights below.

`/atw debug` (section **Analytics and export**) has switches, counts and times only, no names, so its text is safe to
paste. Screenshots and exports show names: replace them with `<player>`.

## 1. Before turning the switches on

Do this once, right after the install, if you can.

1. With the switches off: no *Recordings · Analytics* selector, no *Analytics* card in a report, no *Export* button;
   `/atw debug` says `switches: analytics off, export off`.
2. Turn them on as above. No Lua error and no chat message at login; no window opens by itself; the old recordings are
   there, unchanged.

## 2. Make the recordings

Record, waiting 5 s after each fight:

1. In a **party**, the **same enemy** (the same creature) at least **four times**, one to three minutes each: the tank
   pulls, you go above Warning and Danger, take the enemy once, the tank takes it back.
2. In the same set, one fight with **other thresholds** (for example Warning 70 %, Danger 85 % in the *Monitor* card;
   put them back afterwards), one **interrupted** by a `/reload` in combat, and, if you can, one in **another role** (or
   another character) and one in **another group size or difficulty**.
3. A **dungeon**: trash and a boss. A **raid** if you can. A fight against a second, different enemy.
4. One **long** fight (a raid boss or the dummy for ten minutes) for the export of step 9.

## 3. The *Analytics* card of a report (the three outcomes)

1. Open a report: below the *Timeline* card, *Building analytics…* then the **Analytics** card. The report opens as
   quickly as before.
2. Check each line against what you saw and against the report's own cards: readable samples, threshold crossings
   (with *thresholds 82 / 91*), time with a unit in Warning or Danger, changes of the enemy's holder (the first holder of
   a pull is not one), taken by a non-tank, unstable intervals, risk situations, closest to the tank (never the unit
   holding the enemy). Where the report has the same figure the **numbers are identical**.
3. Hold the mouse over each line: category, what it measures, basis, readable samples and coverage, and for a missing or
   *at least* value the reason. Can you trace each number to something in the report or the replay?
4. **Values** outcome: all lines. **State only** (open a recording of the [M5 checklist, step 5](M5.md#5-dungeon-and-raid-the-three-outcomes-and-a-mixed-fight-probe-p3)):
   percentages *Not available*, crossings and times from the **game states**, no percentage anywhere. **Nothing
   readable**: only the readable samples and the note *Nothing was readable in this fight: only the context can be
   described.*
5. Note, for each context (party, dungeon trash, boss, raid), which outcome you got and **how many lines were
   *Insufficient data* or *Not available*** (probe P3).

## 4. *Insufficient data* under half the samples (ANA-02)

1. Make a fight where much of the data cannot be read: in a raid lower *Units per read* below the group size, or leave
   the threat list or stay without a monitored enemy for **more than half** of the fight.
2. With fewer than half the samples readable, or the enemy monitored for less than half of combat, the metrics say
   *Insufficient data* with the percentage (*fewer than half the samples readable: 38 %*), never a number. The report may
   still show a lower bound: that is expected.
3. A fight just above half shows numbers, with *at least* where data were missing. Does 50 % feel right (Q22)? If you
   cannot make such a fight, write *skipped*.

## 5. Unstable intervals and the replay

1. In a fight with several changes within a few seconds, the card lists *N intervals* and the first three with their
   time and number of changes; check them against the timeline.
2. Click one: the **replay** opens at its start. Close it.
3. A calm fight says *No unstable interval recorded* (never *stable*).
4. Are 3 changes within 10 s too many or too few on your fights? In a raid, does the pull alone make an interval?

## 6. The Analytics page and the comparison

1. In **Reports**, the *Recordings · Analytics* selector: *Analytics* lists the enemies, most recent first, with fights,
   time in combat, latest date and readable samples; unknown enemies are one row and cannot be compared. `/atw reports`
   opens *Recordings*.
2. Click your enemy: *Building …* then the table, the *All fights* row and one row per fight, newest first, only that
   enemy. Check some values against the reports. How long did it take (probe P10)?
3. The mouse over a value says category, basis and reason; over *All fights*, median, total, lowest and highest with
   date, and how many fights. With one comparable fight: *Only one comparable fight*.
4. **Filters**: *Same group size*, *Same difficulty*, *Same role* off and on; the rows and the line about fights left out
   change. With a filter off, your own columns of a fight in another role say *Not comparable*.
5. The fight with **other thresholds** says *Not comparable* (with both thresholds) for the state metrics and is not in
   their aggregates. The **interrupted** fight is marked *at least* and so are the aggregates it enters; the one after
   the `/reload` is a separate row.
6. Click a row: its report opens. The card's *Compare with … other fights* opens the page on that enemy.
7. Is the enemy matched correctly? Two different enemies with the same name should not be in one comparison if the
   creature number is readable (probe P9); note which happens.
8. Start a comparison and **enter combat**: *Paused during combat*; it resumes after. Open the page and the cards in
   combat: no error, no blocked action.
9. A new recording shows **Refresh**; deleting one removes it from the comparison; deleting the one whose report is open
   closes the card.
10. With many recordings (the more the better) open the page and compare 20 fights: any hitch? Copy `/atw debug`
    *Analytics and export* (*metrics last build*, *compare last set*).

## 7. Sizes, scales and Italian

1. The main window at its smallest size, a middle one and the largest; window scale 50 %, 100 %, 200 %; UI scale 0.64
   and 1.0; **English and Italian**.
2. The comparison table: columns disappear from the end in a narrow window and stay in the row tooltip; no overlapping or
   cut text you cannot read; the letters **D / C / E** (**R / C / S** in Italian) and the legend are understandable.
3. The selector, the small filter switches, the long tooltips (do they fit on screen?) and the report's buttons in a
   narrow card (they may take two lines).
4. In the **three themes**: *Insufficient data*, *Not available*, *Not comparable* and *at least* are readable and never
   look like a normal number.

## 8. Export: every content and format

Open *Export* from a report (*This fight*, *Events*, *Readings*) and from *Compare fights* (*Comparison*).

1. The box opens with the text **already selected**; the warning about names is above it; *Text* is off with *CSV only*
   for *Events* and *Readings*. Typing in the field changes nothing; `Esc` closes it; nothing appears in any chat.
2. For each of **This fight (Text, CSV)**, **Events (CSV)**, **Readings (CSV)** and **Comparison (Text, CSV)**: press
   `Ctrl` + `C`, paste in a text editor. The whole text arrived (first and last lines), accents and `–`, `·`, `…` are
   correct, a `|` was copied as **one** `|`, not two.
3. **Discord**: paste each part of a *Text* export. Each part is one message, a complete code block, with `(1/3)` in the
   title, under 2,000 characters, no line broken, no mention triggered, accents correct.
4. **Spreadsheet**: save each CSV as a file (UTF-8) and open it with the comma separator. One column per header, quoted
   values intact, accents correct, a text starting with `=`, `+`, `-` or `@` shown as text with an apostrophe (not run as
   a formula), decimals read as numbers (note your spreadsheet's language if they are not).
5. Compare a few values with the report. Every missing value has a status (`na`, `insufficient`, …) or words in the
   text; none is a 0 or an unexplained empty cell. In the comparison CSV the last columns list the metrics that are *at
   least*, not available, insufficient, not comparable, detected or calculated.

## 9. Names replaced, and a long fight

1. Switch **Replace names with Player 1, Player 2…** on: the warning changes; copy each content. **Search the pasted
   text for every name of your group, your own, your pet's and the realm**: none must be there. You are *You*, the same
   person has the same number everywhere; enemy and zone names stay. In the *Text* export in Italian the words are
   translated, in the CSV they stay English.
2. Close and reopen the box: the choices are kept; after `/reload` the names switch is off again.
3. **Long fight** (step 2.4): *Readings*. *Building export…*, then the status line (*about 256 KB*, *N rows left out*).
   Time how long the box takes to show the text (probe P10): any freeze at that moment? Scroll to the end,
   `Ctrl` + `A`, `Ctrl` + `C`, paste: is the **whole** text there, ending with a complete row? How many rows? The note
   about rows left out must not be in the pasted text. The same with *Events*.
4. Open the box in combat and close it: no error. Delete the recording while the box is open (or while a comparison box
   holds it): *This recording was deleted.*
5. Copy `/atw debug` *Analytics and export* (*export last*). If the client cuts or freezes on a long text, write the
   largest size that works.

## 10. Nothing leaves, nothing changes

1. Over the whole check, no message in party, raid, guild, whisper or any channel came from the addon.
2. After exporting and comparing, `/reload`: the recordings are the same, the page and box choices are back to default.

## What to report if something does not work

| Symptom | What to send |
|---|---|
| Lua error or blocked action | the error text, what you did, `/atw debug` |
| A wrong or untraceable number | context, what you saw, the report's and the card's values, the tooltip text (names hidden), `/atw debug` |
| A wrong comparison | filters, the rows involved, thresholds, group, difficulty, role, `/atw debug` |
| A wrong export | content, format, where you pasted it, a few lines **with names replaced** |
| Freeze, slowness, cut text | steps 6.10 and 9.3 numbers, length of the fight, group size, other addons |
| Unreadable or cut text | screenshot (names hidden), window size, scale, language, theme |
