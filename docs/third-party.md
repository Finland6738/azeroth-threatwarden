# Third-party material and licences

> Adapted from Azeroth Accord (docs/third-party.md), same owner, GPL-3.0
> ([ADR 0012](adr/0012-reuse-accord-and-unspoken-foundations.md)).

The addon is GPL-3.0 ([LICENSE](../LICENSE), [ADR 0011](adr/0011-license-gpl-3.md)). This page records where every
library, font and picture that ships in the package comes from and under which licence. It is the single place to update
when one is added: `tools/check_addon.py` fails when a file of `AzerothThreatwarden/Media/` is not named here or a font
folder has no licence text.

## Libraries (`AzerothThreatwarden/Libs/`, fetched, never committed)

Each library is a whole repository at a tag, pinned in [`.pkgmeta`](../.pkgmeta): `tools/fetch_libs.py` downloads it for
development and CI, the BigWigs packager embeds it in a release. The licence is the library's own; its licence file or
header travels inside its folder. [SPEC-01 §4](specs/SPEC-01-platform-architecture.md#4-librerie) says which parts the
addon loads (`AzerothThreatwarden/embeds.xml`).

| Library | Pinned tag | Source | Loaded | Licence, as the library states it |
|---|---|---|---|---|
| **Ace3** | `Release-r1403` | <https://github.com/WoWUIDev/Ace3> | LibStub, CallbackHandler-1.0, AceAddon-3.0, AceEvent-3.0, AceConsole-3.0 | BSD-style, `Libs/Ace3/LICENSE.txt` (no standalone redistribution of Ace3) |
| **LibDataBroker-1.1** | `v1.1.4` | <https://github.com/tekkub/libdatabroker-1-1> | `LibDataBroker-1.1.lua` | the repository carries no licence file; it is distributed by its author for embedding in addons |
| **LibDBIcon-1.0** | `v8.0.4` | <https://github.com/wowace-clone/LibDBIcon-1.0> | `LibDBIcon-1.0/lib.xml` | `X-License: GPLv2 or later` in `LibDBIcon-1.0.toc` |

The folders come whole, so the package also holds parts of these repositories that the addon does not load (other Ace3
libraries, the copies of LibStub, CallbackHandler and LibDataBroker inside LibDBIcon).

## Fonts (`AzerothThreatwarden/Media/Fonts/`)

All three families are under the **SIL Open Font License, Version 1.1**; each family's licence text ships next to it.
[`tools/make_fonts.py`](../tools/make_fonts.py) copies the files byte for byte from the sibling repository Finland Dragon
Credit Points (same owner), or from Azeroth Accord's identical copy when that folder is not there; the files in this
repository were copied from **Finland Dragon Credit Points** (compared byte for byte with Azeroth Accord's: the same).

| Files | Family and source | Changes | Licence file |
|---|---|---|---|
| `Outfit-Regular.ttf`, `Outfit-Medium.ttf`, `Outfit-SemiBold.ttf` | Outfit, <https://github.com/google/fonts> (`ofl/outfit`) | static instances cut from the variable font, reduced to a Latin subset (no Reserved Font Name) | `Outfit-OFL.txt` |
| `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Medium.ttf` | JetBrains Mono, <https://github.com/google/fonts> (`ofl/jetbrainsmono`) | static instances cut from the variable font, Latin subset (no Reserved Font Name) | `JetBrainsMono-OFL.txt` |
| `Orbitron-Bold.ttf` | Orbitron, <https://github.com/theleagueof/orbitron> | **whole and unmodified** (Reserved Font Name "Orbitron") | `Orbitron-OFL.txt` |

## Textures and icons (`AzerothThreatwarden/Media/`)

Generated by [`tools/make_media.py`](../tools/make_media.py) (adapted from Azeroth Accord), white with an alpha channel
and tinted by the theme. They are drawn with Pillow shapes for this addon, so they carry no third-party artwork and are
covered by the GPL-3.0.

| Files | What they are |
|---|---|
| `rr_fill_4.tga`, `rr_fill_8.tga`, `rr_fill_12.tga`, `rr_fill_18.tga` | filled rounded rectangles (9-slice) |
| `rr_ring_4.tga`, `rr_ring_8.tga`, `rr_ring_12.tga`, `rr_ring_18.tga` | 1 px rings of the same shapes |
| `shadow.tga`, `glow_s.tga`, `glow_l.tga` | blurred shapes for shadows and glows |
| `pill.tga`, `circle.tga`, `blob_radial.tga`, `dash.tga` | pill, circle, radial spot, dash for dashed outlines |
| `icons.tga` | the icon sheet (16 px cells), including the four state icons, lock and unlock, tank, trends, predict and stale |

## Logos (`AzerothThreatwarden/Media/`)

| Files | Source | Rights |
|---|---|---|
| `logo_256.tga` (the whole picture), `logo_64.tga` (cut to the square around the shield) | `assets/logo-source.webp`, the addon's logo, **supplied by the repository owner** | the owner's picture, shipped as the addon's logo |
| `nebula_dark_256.tga`, `nebula_light_256.tga` | `assets/nebula-logo-dark.png`, `assets/nebula-logo-light.png`, the logos of the Italian guild NEBULA | **used with the guild's permission** for the credits; not covered by the GPL-3.0 grant for any other use |

The `assets/` folder holds the source pictures only and is never part of the package.

## Game art

No Blizzard artwork is copied into the repository. Game textures and fonts are referenced by name at run time only,
never shipped as files.
